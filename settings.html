Security recommendations
  • Deploy the web app as Anyone in the organisation, not Anyone with the link.
  • Turn off ALLOWALL iframe embedding if you do not host this app in a custom frame.
  • Use a shorter session TTL (for example 1 hour) for administrator accounts.
  • Staff dashboards stay limited to their own tasks; staff lookup is admin-only.
  • Review the audit log for logins, user create, and attachment downloads.
  • Keep backups of the spreadsheet and the attachments Drive folder.
  • Do not put session tokens in URLs. Prefer long passphrases; a stronger password hash is needed if you leave Apps Script.
